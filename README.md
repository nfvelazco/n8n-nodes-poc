# n8n Custom Logger Nodes

Este repositorio contiene nodos personalizados para n8n, incluyendo un nodo de logger personalizado y un nodo de ejemplo HelloWorld.

## Estructura
- `n8n-nodes-custom-logger/`: Contiene los nodos personalizados y archivos relacionados.
  - `src/CustomLoggerNode.ts`: Nodo de logger personalizado.
  - `src/HelloWorldNode.ts`: Nodo de ejemplo HelloWorld.
  - `custom_logs.sql`: Script SQL relacionado con los logs.

## Instalación y uso
1. Clona este repositorio.
2. Instala las dependencias con `npm install` dentro de la carpeta `n8n-nodes-custom-logger`.
3. Sigue la documentación de n8n para agregar nodos personalizados.
